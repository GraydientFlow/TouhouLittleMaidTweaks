# Graydient's Touhou Little Maid Tweaks

[English](README.md) | 简体中文

[**车万女仆（Touhou Little Maid）**](https://github.com/TartaricAcid/TouhouLittleMaid)（由 tartaric_acid 及贡献者开发）的独立附属模组。

| 当前版本 | Minecraft | 加载器 | 许可证 |
|---|---|---|---|
| `1.1.0-a3` | `1.21.1` | NeoForge | [GPL-3.0-or-later](LICENSE) |

---

## 关于本模组

这个模组是我为一个小型私人服务器开发的，当时服务器里的玩家想要一些日常便利性改动。本模组尽量保留车万女仆原有的女仆行为逻辑，只做一些小的体验（QoL）和性能调整。添加的功能不影响游戏平衡。

**项目状态：** 1.1.0-a3 为本地测试版，新增无线 I/O 数量上限和多饰品协同传输，客户端实机验收尚未完成。

---

## 功能一览

| 功能 | 作用 |
|---|---|
| **女仆资源包共享** | 在联机时直接看到好友的女仆自定义模型、椅子和语音包。 |
| **多人联机权限** | 可以查看其他玩家女仆的装备，同时防止别人拿走物品或乱改工作。 |
| **智能动物管理** | 女仆不会杀光家里最后几只羊，还能共同管理围栏并提供无限牛奶。 |
| **工作优先座位** | 女仆不会再霸占椅子不放，也不会在有工作时卡在座位上。 |
| **幽灵栅栏门** | 女仆可以直接穿过关闭的栅栏门，不会把动物放跑。 |
| **女仆协助跳夜** | 睡觉的女仆可以帮忙跳过夜晚，不会因为有人挂机或忙别的事而卡夜。 |
| **自定义女仆排班** | 修改白班和夜班女仆工作、休息和睡觉的时间。 |
| **双人棋类对局** | 在棋盘上和另一名玩家下国际象棋、中国象棋或五子棋。 |
| **同种工具自动补充** | 工具用坏时，女仆自动从背包换上同款备用工具。 |
| **存储 I/O 虚拟过滤** | 设置无线 I/O 过滤时不用再放一把真工具进去。 |
| **掉落物拾取延迟** | 防止女仆在你刚丢出物品时立刻跑过来捡走。 |

## 安装

### 必需模组

将以下模组与本附属模组一起放入 `mods` 文件夹，下载时选择适用于 Minecraft 1.21.1 NeoForge 的版本。

| 模组 | 所需版本 | 安装端 |
|---|---|---|
| **车万女仆（Touhou Little Maid）** | `1.5.3` | 客户端与服务器 |
| **Cloth Config** | `15.0.140+`（`15.x`） | 仅客户端 |

机械动力（Create）、「农耕与烹饪」及 Carry On 为可选联动。完整构建目标见 [project.json](project.json)。

### 安装步骤

1. 把本附属模组与车万女仆放进服务器和每个客户端的 `mods` 文件夹；单人游戏只需安装在客户端。
2. 把 Cloth Config 放进每个客户端的 `mods` 文件夹。
3. 重启游戏或服务器。

## 配置与命令

在游戏内打开 **车万女仆 > 配置 > 渐变灰的女仆调整**：

- **房主与服务器管理员**可以修改服务器规则。
- **其他玩家**可以查看当前规则，并管理自己的**女仆资源包**共享选项。
- **语言：** 支持**英文**（`en_us`）与**简体中文**（`zh_cn`）。
- **配置文件：** 保存在 `config/touhou_little_maid_tweaks-<模块>.toml`（包含 `server`、`jobs`、`schedule`、`sleep`、`pickup` 与 `permissions`），世界存档 `serverconfig/` 下的同名文件可单独覆盖该世界设置。

| 命令 | 作用 |
|---|---|
| `/maidsleep` | 让当前维度所有符合条件的入睡女仆计入今晚跳夜。 |
| `/maidsleep cancel` | 在天亮前排除当前维度的女仆，不计入今晚跳夜。 |
| `/maidsleep status` | 查看当前维度的睡眠设置和符合条件的女仆数量。 |
| `/automaidsleep <true\|false>` | 开启或关闭女仆自动跳夜（默认仅限房主/管理员；`true` 同时清除今晚的取消状态）。 |

## 功能详情

### 1. 女仆资源包共享
*现在可以直接看到好友的女仆模型、椅子和语音包了。*

- 在服务器或局域网中自动同步从车万女仆官方目录下载的外观，以及玩家自己添加的模型、椅子和音效 ZIP 包。
- 每个玩家可以在**女仆资源包**设置里按服务器或世界单独开启，不开启不会改动本地文件。
- 自定义资源包可能包含 JavaScript 脚本，所以需要服务器允许，并且客户端会有 5 秒确认提示。

---

### 2. 多人联机权限
*可以查看其他玩家女仆的装备，同时防止别人拿走物品或改动工作。*

| 非主人玩家的操作 | 默认设置 |
|---|---|
| 打开并查看女仆的物品栏、装备与工作设置 | 允许 |
| 拿取或放入物品 | 仅限主人 |
| 修改工作或设置 | 仅限主人 |
| 使用 Carry On 搬起女仆 | 仅限主人 |

房主或管理员可以在**玩家权限**里放开这些限制。

---

### 3. 智能动物管理
*女仆不会再杀光家里最后几只羊，还能共同管理整个围栏并提供无限牛奶。*

- **数量上限控制：** 默认保留**每种动物至少两只成年个体**，并且不会杀幼崽。支持按**动物体积**、**动物占地面积**或**按种类计数**设置上限（默认每 4 格地面 `1.5` 头牛当量，同时支持车万女仆原版与「农耕与烹饪」）。
- **动物管理站：** 把管理站放在围栏内、贴着围栏外侧放置，或者直接装在栅栏上，附近的繁殖女仆就会按共享设置一起管理这个围栏，不需要手动分配。
- **共享围栏设置：** 监测同一个围栏的管理站共用规则。拆除安装在栅栏上的管理站会恢复原来的栅栏。关闭管理站功能后，它只作为装饰，不参与工作、供奶或打开设置菜单。
- **无限牛奶：** 只要封闭围栏里有至少一头成年牛，拿**空桶**右键管理站就能无限接牛奶。

```text
合成配方：
S S S    S = 任意木台阶
. B .    B = 木桶
. S .    . = 空
```

---

### 4. 工作优先座位与座位锁定
*女仆不会再霸占椅子不放，也不会在有工作时卡在座位上。*

- 闲置的女仆可以坐空椅子（包括机械动力 Create 的坐垫），有需要移动的工作时会自动站起来。
- 需要坐着工作的女仆（比如在工作区域内找钓位的钓鱼女仆，即使视线被挡住也能绕路过去）会自动接替未锁定的休闲座位。
- 如果想让女仆一直坐在某个位置，在她坐下时关闭**实体骑乘 / 允许坐下**即可锁定。

---

### 5. 幽灵栅栏门
*女仆可以直接穿过关闭的栅栏门，不会把围栏里的动物放跑。*

- 把女仆的栅栏门设置切到 **关闭 / 开启 / 幽灵**。
- 在**幽灵**模式下，女仆可以直接穿过关闭的栅栏门，而栅栏门对动物和其他生物仍然保持关闭。

---

### 其他改动

- **女仆协助跳夜：** 在**女仆睡眠**里打开总开关（默认关闭）。**女仆协助跳夜**（默认开启）让入睡女仆按每名 `0.5` 个玩家的比例计入睡眠人数；**自动跳夜**（默认关闭）让女仆独立跳过夜晚。手动和自动的女仆独立跳夜默认都要等到 `22:30`；协助已入睡的玩家则遵循原版时间规则。睡眠命令只改变跳夜计数许可，不改变工作、移动或上床时间。
- **自定义女仆排班：** 在**女仆排班**里按 **HH:MM** 修改时间（白班默认：`06:00` 工作、`18:00` 休息、`22:00` 睡觉；夜班默认：`18:00` 工作、`14:00` 休息、`06:00` 睡觉）。
- **双人棋类对局：** 棋盘没女仆坐着时，空手右键就能和另一个玩家下国际象棋、中国象棋或五子棋；点重置区域重新开局。
- **同种工具自动补充：** 手上的工具用坏时，自动从女仆背包里换上同款备用工具，保留附魔和耐久。
- **无线 I/O 数量上限：** 用物品堆左键点击过滤格，或在物品栏中 Shift 单击物品，可复制物品类型和数量，不消耗真实物品。右键每次增加一个虚拟物品。箱子 → 女仆白名单模式下，将鼠标移到标记上滚动，可设置 **1–128** 的携带上限。已有标记初始上限为 **1**。多个已装备 I/O 会优先取出物品；存入 I/O 保留同种物品的最高取出预留量，仅存入多余部分。存入过滤标记固定为 **1**。取出黑名单保留原有类型过滤行为。原版过滤格中的真实物品仅退还一次。
- **掉落物拾取延迟：** 女仆对脚边以外的新掉落物（包括物品磁铁饰品）默认等 **15 秒**再去捡，脚边的物品还是直接捡。
